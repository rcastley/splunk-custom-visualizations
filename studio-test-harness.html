Getting started
  1. Select a built extension bundle.
  2. Adjust generated option controls and data sliders.
  3. Use No-data, Loading, mode, and resize controls to exercise lifecycle states.

            
Theme
The sun/moon icon changes both the harness chrome and the theme reported through DashboardExtensionAPI. In light mode, the contrast icon changes only the preview backdrop.

            
Preview scope
Enter exact dimensions, click Fit, or drag the lower-right handle. The iframe remains isolated and receives dimensions through the native API mock.

            
Advanced diagnostics
Use Advanced State for raw options, data sources, and tokens. Open Events in the telemetry strip for drilldowns, setOptions, and errors.
